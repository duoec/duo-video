# 自动化视频处理系统 GUI

## 项目概述

这是一个基于GUI的自动化视频处理系统，支持自动下载、处理和上传视频文件。系统具备智能图像识别、单实例控制、实时进度监控等功能。

## 快速开始

### 环境准备
```bash
# 安装依赖
pip install -r requirements.txt
```



### 启动程序

```bash
./start_gui.sh
```

或直接运行：
```bash
python main_gui.py
```



## 功能特性

✅ **自动启动服务** - GUI启动后服务默认运行，无需手动启动

✅ **双栏界面** - 左侧操作面板，右侧日志显示

✅ **实时监控** - 显示服务器地址、任务状态、下载/上传进度

✅ **智能图像识别** - 自动检测剪映界面元素并操作

✅ **单实例控制** - 基于端口的单实例机制，防止重复启动

✅ **优雅重启** - 支持一键关闭旧实例并启动新实例

✅ **循环检测** - 图像检测失败时自动重试，提高成功率

✅ **日志记录** - 实时显示系统日志和操作状态

✅ **暂停/恢复** - 灵活的任务控制

✅ **进度跟踪** - 实时显示下载和上传进度及速度



## 界面说明

### 左侧操作面板
- **服务器信息** - 显示当前配置的服务器地址

- **任务状态** - 显示当前处理任务和状态

## 故障排除

### 问题：程序启动后立即退出
**原因：** 端口被占用
**解决方案：** 等待几秒后重试，系统会自动重试获取端口

### 问题：图像识别失败
**原因：** 界面元素位置变化或分辨率问题
**解决方案：** 检查images目录下的图像模板是否匹配当前界面

### 问题：权限不足
**原因：** macOS屏幕录制权限
**解决方案：** 在系统偏好设置中授予屏幕录制权限

### 问题：服务无法启动
**原因：** 配置文件错误或网络问题
**解决方案：** 检查app_config.ini配置文件

## 系统要求

- **操作系统**：macOS（推荐）
- **Python版本**：3.12+
- **内存**：至少4GB RAM
- **磁盘空间**：至少1GB可用空间（用于缓存和临时文件）
- **权限**：屏幕录制权限（用于图像识别）
