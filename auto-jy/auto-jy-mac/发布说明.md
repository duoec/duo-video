# 自动化视频处理系统 - 独立应用版

## 概述
这是一个独立的 macOS 应用程序，无需安装 Python 或任何依赖项即可运行。该应用实现了自动化视频处理功能，支持自动下载、处理和上传视频文件。

## 安装说明

### 方法一：直接运行（推荐）
1. 双击 `自动化视频处理系统.app` 文件运行应用
2. 首次运行时，macOS 可能会提示应用来自未知开发者，需要在「系统偏好设置」>「安全性与隐私」中允许运行

### 方法二：安装到应用程序文件夹
1. 将 `自动化视频处理系统.app` 拖拽到 `Applications` 文件夹
2. 通过 Spotlight 或 Launchpad 启动应用

## 配置文件
- 应用需要 `app_config.ini` 配置文件才能正常工作
- 请确保配置文件与应用在同一目录下，或按照应用提示指定配置文件路径

## 系统要求
- macOS 10.13 或更高版本
- ARM64 或 x86_64 架构
- 至少4GB RAM
- 至少1GB可用磁盘空间

## 权限要求
- 屏幕录制权限：用于图像识别和自动化操作
- 在首次运行时，系统可能会提示您授予这些权限

## 故障排除

### 首次运行被阻止
如果遇到 "无法打开，因为 Apple 无法检查其是否包含恶意软件" 的提示：
1. 打开「系统偏好设置」>「安全性与隐私」
2. 在「通用」标签页中点击「仍要打开」
3. 或者在终端中运行以下命令：
   ```bash
   xattr -d com.apple.quarantine "/path/to/自动化视频处理系统.app"
   ```

### 图像识别失败
- 检查剪映界面是否与预期一致
- 确认屏幕分辨率和缩放比例是否影响图像匹配
- 检查 `images/` 目录中的图像模板是否与当前界面匹配

### 应用闪退
- 确保 `app_config.ini` 配置文件存在且格式正确
- 检查网络连接是否正常
- 查看日志文件以获取更多错误信息

### 权限问题
- 如遇屏幕录制权限问题，请前往「系统偏好设置」>「安全性与隐私」>「隐私」>「屏幕录制」中添加应用

## 功能特性

✅ **自动启动服务** - GUI启动后服务默认运行，无需手动启动

✅ **双栏界面** - 左侧操作面板，右侧日志显示

✅ **实时监控** - 显示服务器地址、任务状态、下载/上传进度

✅ **智能图像识别** - 自动检测剪映界面元素并操作

✅ **单实例控制** - 基于端口的单实例机制，防止重复启动

✅ **优雅重启** - 支持一键关闭旧实例并启动新实例

✅ **循环检测** - 图像检测失败时自动重试，提高成功率

✅ **日志记录** - 实时显示系统日志和操作状态

✅ **暂停/恢复** - 灵活的任务控制

✅ **进度跟踪** - 实时显示下载和上传进度及速度

## 技术细节
- 此应用使用 PyInstaller 打包
- 包含完整的 Python 解释器和所有依赖项（PyQt6、pyautogui、requests等）
- 应用大小较大是因为包含了所有必需的库
- 基于TCP端口54321的单实例控制机制
